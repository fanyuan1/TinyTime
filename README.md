# TinyTime - Meeting Scheduler

A modern, lightweight meeting scheduling app built with React and Vite. PURE VIBES!

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the application by modifying files in the `src/` directory. The page auto-updates as you edit the file.

## Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deploy

You can deploy this application to various platforms:

- **Vercel**: Import your repository on [Vercel](https://vercel.com)
- **Netlify**: Deploy directly from GitHub on [Netlify](https://netlify.com)
- **Firebase Hosting**: Use `firebase deploy` after configuring Firebase hosting

For more details on deployment, refer to the [Vite deployment documentation](https://vitejs.dev/guide/static-deploy.html).
